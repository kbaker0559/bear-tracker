# Bear Tracker Weekly Workflow

## Thursday
1. Import and apply Paul’s pairings.
2. Stop after the pairings are saved.

## Friday
1. Review every player’s current course handicap.
2. Review every player’s Points Needed quota.
3. Mark each player reviewed.

## Saturday Morning
1. Open Player Status.
2. Add late players, remove withdrawals/DNS players, and make final card-assignment changes.
3. Mark Player Status complete.
4. Reorganize each scorecard into the same order as the paper card.
5. Mark Scorecard Order complete.
6. Begin player arrivals/check-in.

Mission Control follows this task order. It is driven by completed work rather than the calendar date.
