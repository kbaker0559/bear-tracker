# Repository AT-34.1 — Rename Tournament

This build enables only repository-backed rename in the visible Tournament Library.

## Acceptance test

1. Rename a tournament.
2. Restart Vite.
3. Confirm the new name remains.
4. Confirm the same tournament remains current and its players/cards are unchanged.

Duplicate, archive, delete, new tournament, migration, OCR, and normal tournament-data saving are unchanged.
